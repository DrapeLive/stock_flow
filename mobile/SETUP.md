# Stock Flow Mobile (Android Admin App)

Flutter companion for the Stock Flow warehouse. Mirrors the web admin
(`frontend/`) — items, analytics, users, summary, bulk import, profile.

> This folder currently contains **source only** (`lib/`, `pubspec.yaml`,
> `analysis_options.yaml`). Platform scaffolding is generated by `flutter
> create` (see below). Nothing here will build until that step runs.

## 1. Scaffold the Android platform

Run this once, **in this folder**:

```sh
flutter create --platforms android --org com.xlapparals .
```

This generates `android/` and `test/`. It keeps the existing
`pubspec.yaml`, though it may add missing helper files.

## 2. Android manifest tweaks

Edit `android/app/src/main/AndroidManifest.xml`:

- Add under `<manifest>` (before `<application>`):

```xml
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.CAMERA" />
```

- The dev backend is plain HTTP (`http://10.0.2.2:8000`), so add on
  `<application>`:

```xml
android:usesCleartextTraffic="true"
```

(For a real build against `https://api.xlapparals.in` you can drop the
cleartext flag and pass `MEDIA_DOMAIN` — see below.)

## 3. Dependencies

```sh
flutter pub get
```

## 4. Run / build

```sh
# Emulator → uses 10.0.2.2:8000 by default
flutter run

# Physical phone → your LAN Django dev server
flutter run --dart-define=API_BASE_URL=http://192.168.1.5:8000

# Release APK (with media domain for images)
flutter build apk --release \
  --dart-define=API_BASE_URL=https://api.xlapparals.in \
  --dart-define=MEDIA_DOMAIN=api.xlapparals.in
```

`MEDIA_DOMAIN` — the domain images are served from (same value as
`NEXT_PUBLIC_MEDIA_DOMAIN` in `frontend/.env*`). Resolved images fall back to
`API_BASE_URL` when empty.

## 5. Verify

```sh
flutter analyze
flutter test
flutter build apk --debug
```

`pubspec.yaml` deps already include everything used by the code:
`excel` (bulk import), `file_picker` (spreadsheet picker),
`share_plus` + `path_provider` (template download), `pdf`/`printing`
(QR labels), `mobile_scanner` (scan-to-assign), `qr_flutter`, Dio,
Riverpod, go_router, Hive CE, cached_network_image, connectivity_plus.

## Notes / known parity gaps

- No Settings/Admins tabs, no superuser features — admin-only by design.
- Agent detail omits the “Download PDF” item-assignment export.
- `fl_chart` is in pubspec but unused (analytics uses CustomPaint to avoid a
  version API risk); you can remove it.
